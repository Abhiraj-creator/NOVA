# UI Context

## Theme

NOVA is a premium editorial technology product experience: near-black campaign surfaces, warm white content areas, high-contrast typography, restrained borders, and a controlled hot-pink accent. It is original while taking visual discipline—not layouts or assets—from contemporary AI-infrastructure websites.

## Typography

Use a modern grotesk-style system stack with high-weight display headings, compact UI labels, controlled line lengths, and monospaced metadata only where it reinforces the product-interface feel.

## Layout Patterns

- Editorial asymmetric hero with an original built-in product visualization.
- Full-width statements and split product layouts break up card grids.
- Small radius, thin borders, minimal shadows, and large intentional spacing.
- Accent remains limited to important actions, active states, and data highlights.

## Animation and Icons

GSAP supplies subtle entrance and UI transitions with reduced-motion support. Lucide React provides stroke-based icons. Avoid gradients, glassmorphism, neon effects, and generic AI imagery.
